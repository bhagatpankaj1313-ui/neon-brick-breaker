# Neon Brick Breaker

A neon-styled brick-breaker arcade game that runs entirely in the browser. No build step, no dependencies — just open `index.html`.

## Play it
- Open `index.html` in any modern browser, or
- Enable **GitHub Pages** (Settings → Pages → Deploy from branch → `main`) for a live playable link.

## Features
- 5 hand-designed sectors with escalating speed and tougher bricks
- Combo scoring with up to x8 multiplier
- Power-ups: Wide paddle, Multiball, Slow-mo, Floor shield
- Particles, screen shake, and synthesized sound effects (Web Audio, no audio files)
- Keyboard (A/D or arrow keys, Space) and touch controls
- Light/dark mode that follows your system

## Tech
Single self-contained HTML file — Canvas 2D rendering + Web Audio API. Zero frameworks, zero assets.

Built with Muse (Meta's personal AI agent).
